# 🚀 Hendry Bambang - Developer & AI Engineer Portfolio

A modern, high-performance, visually captivating developer portfolio web application built with **React**, **Vite**, **Vanilla CSS Glassmorphism**, and **Interactive Canvas Background**.

![Portfolio Preview](https://raw.githubusercontent.com/workhendry20-creator/my-portofolio/main/dist/assets/preview.png)

## ✨ Features

- **⚡ Interactive Particle Canvas**: Dynamic floating node network with cursor interaction and glowing particle effects.
- **🎨 Glassmorphism & Modern Styling**: Sleek cyber dark mode & clean light mode toggling with smooth gradients.
- **💻 Dynamic Hero & Typing Effect**: Animated role typewriter, status badge, and interactive code terminal card.
- **📊 Skills & Matrix**: Categorized tech stack tabs (Frontend, Backend, DevOps/Cloud, AI & Innovation) with visual proficiency indicators.
- **🚀 Featured Projects Gallery**: Category filtering, gradient project cards, metrics highlights, live demo links, GitHub repositories, and interactive detail modals.
- **💼 Interactive Timeline**: Vertical career milestones with accomplishment highlights and collaborator testimonials.
- **✉️ Working Contact Form**: Live client-side input validation and instant feedback states.
- **📱 Fully Responsive**: Optimized for Mobile, Tablet, and Desktop displays.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 5, Lucide Icons, Vanilla CSS (CSS Modules & Custom Properties)
- **Effects & Canvas**: HTML5 Canvas API, WebGL Shader-inspired dynamic particle calculations
- **Deployment**: Compatible with Vercel, Netlify, GitHub Pages, or any static host

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/workhendry20-creator/my-portofolio.git
   cd my-portofolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🚀 Deployment Instructions

### Deploy to Vercel (Recommended)
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"New Project"**.
3. Import `my-portofolio` repository.
4. Framework Preset: **Vite**.
5. Click **Deploy**.

### Deploy to Netlify
1. Connect Netlify to your GitHub account.
2. Select `my-portofolio` repository.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Click **Deploy Site**.
